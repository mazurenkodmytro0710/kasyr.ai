# Офіційні джерела (держсайти) для перевірки правил ФОП

Ціль: коли держава змінює ставки/строки/форми, ми знаємо, **що саме** треба звірити і **де** це перевіряти.

Нижче не “довідник з податків”, а список офіційних джерел і чекліст того, що може вплинути на застосунок.

## 1) ДПС та Е-кабінет платника

- `cabinet.tax.gov.ua` (Е-кабінет платника):
  - реквізити (IBAN) для сплати податків/ЄСВ за твоєю громадою;
  - стан розрахунків з бюджетом (борг/переплата);
  - подані декларації/квитанції;
  - актуальні форми/подання онлайн.
- `tax.gov.ua` (ДПС України):
  - новини/роз’яснення;
  - довідники/інструкції, які інколи уточнюють практику застосування норм.

Що звіряти:
- дедлайни по подачі/сплаті (особливо якщо є переноси, уточнення, “операційні” зміни);
- реквізити платежів (IBAN може відрізнятися по громадах).

## 2) Нормативна база (Верховна Рада)

- `zakon.rada.gov.ua`:
  - Податковий кодекс України (групи ЄП, строки, ставки);
  - Закон про Державний бюджет на відповідний рік (мінімальна зарплата, прожитковий мінімум);
  - Закон про ЄСВ (база/ставка/пільги);
  - інші закони/зміни, які впливають на ВЗ або адміністрування.

Що звіряти щороку:
- мінімальна зарплата;
- прожитковий мінімум;
- базові формули (ЄСВ, обмеження/ліміти, відсотки).

## 3) НБУ (курс валют)

- `bank.gov.ua`:
  - офіційний курс НБУ по датах (для перерахунків та звірки).

Що звіряти:
- формат/доступність ендпоінтів курсу;
- правила перерахунку для звітності (якщо зміняться).

## 4) Дія та реєстраційні дані

- `diia.gov.ua`:
  - загальні сценарії/інструкції по реєстрації/змінах.
- `usr.minjust.gov.ua` (ЄДР Мін’юсту):
  - перевірка реєстраційних даних ФОП (статус, КВЕДи, дата реєстрації).

Що звіряти:
- як підтягувати/звіряти КВЕДи та статус (якщо користувач вводить вручну, все одно корисно мати джерело перевірки).

## 5) Рішення місцевих рад (ставка ЄП для 1–2 групи)

Ставки ЄП для 1–2 групи встановлюються рішеннями місцевих рад (у межах, визначених законом).

Де перевіряти:
- офіційний сайт твоєї громади/міської ради (розділ “рішення ради”, “нормативні акти”, “регуляторні акти”);
- інколи громади публікують рішення в PDF/сканах: важливо звіряти **рік** та **чинність**.

Що звіряти:
- розмір ставки для твоєї групи;
- дату набрання чинності;
- умови/винятки (в окремих громадах можуть бути специфічні формулювання).

## 6) Перевірка актуальності в коді Kasyr.ai

Коли змінюються дані:
- мінімальна зарплата / прожитковий мінімум -> оновити `server/services/taxService.ts` (`TAX_CONFIG_BY_YEAR`);
- святкові/вихідні переноси дедлайнів -> перевірити блок `UA_HOLIDAYS` у `server/services/taxService.ts`;
- логіка дедлайнів/форм -> звірити генерацію дедлайнів у `server/services/taxService.ts` та синк у `server/services/deadlinesService.ts`.

Рекомендований процес (раз на рік):
1. Звірити бюджетні показники (мінімалка, прожитковий) на `zakon.rada.gov.ua`.
2. Пройти чек “дедлайни” для кожної групи в застосунку і співставити з ДПС/Е-кабінетом.
3. Оновити константи та прогнати `npm run build`.

# Як оновлювати податкові параметри в коді

Цей гайд потрібен, щоб швидко і безпечно оновлювати параметри року (мінімалка, прожитковий, свята), не ламаючи дедлайни та розрахунки.

## Де в коді

Основне:
- `server/services/taxService.ts`
  - `TAX_CONFIG_BY_YEAR` (мінімальна зарплата, прожитковий мінімум)
  - `UA_HOLIDAYS` (свята для перенесення дедлайнів)
  - генерація дедлайнів та розрахунки

Синхронізація дедлайнів:
- `server/services/deadlinesService.ts`

## Що оновлювати

1. `TAX_CONFIG_BY_YEAR[YYYY]`:
- `minWage` (мінімальна зарплата)
- `livingWage` (прожитковий мінімум)

2. `UA_HOLIDAYS[YYYY]`:
- перелік дат свят (ISO `YYYY-MM-DD`)
- якщо свята “переїжджають” або змінюються офіційно, оновити список

## Як перевіряти після оновлення

1. Прогнати збірку:
```bash
npm run build
```

2. Пройти сценарій:
- створити новий акаунт
- пройти onboarding для груп 1/2/3
- відкрити “Дедлайни” і звірити, що дедлайни не “в минулому” як overdue для нового користувача

3. Якщо є сумніви по строках або ставках:
- звірити з джерелами з `docs/OFFICIAL_SOURCES_UA.md`
